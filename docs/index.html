A Chrome extension for the moment a value is on the screen and the Network panel is a wall of calls. Click it. The panel names the request and the JSON field.

Download Source

The field, not the whole payload.

The first row is the exact value. Under it, any other response that also contains that text. Copy the endpoint, the path, or a curl command.

Install

  1. Download the zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select the unzipped folder.
  4. Reload the tab, then start inspecting.

Responses stay in the tab. They are not uploaded. Privacy
